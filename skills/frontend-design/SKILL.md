# Hamnavaz Frontend Design Skill

Based on the principles of Anthropic's official `frontend-design` skill: use a deliberate visual identity, avoid generic/template aesthetics, and make typography, color, layout and motion intentional. Source: https://github.com/anthropics/skills/tree/main/skills/frontend-design

## Hamnavaz direction
- RTL Persian music platform.
- Premium dark/luxury visual language.
- Deep navy/black base with purple neon and restrained gold accents.
- Neon is an accent, not a replacement for hierarchy or readability.
- Mobile-first and accessible.
- Preserve the existing design system; do not introduce a second styling system unnecessarily.

## Before UI changes
1. Identify the user's task and the page's primary job.
2. Reuse existing tokens/components.
3. Make motion purposeful and provide reduced-motion behavior.
4. Check contrast, focus states, touch targets and responsive layout.
5. Verify the real production page after deployment.
