# Hamnavaz Frontend Design Skill

Use this skill for Hamnavaz UI work. Preserve the product's Persian RTL, premium dark music identity, and deliberate visual language. Avoid generic template aesthetics.

## Design rules
- Ground visual choices in music, instruments, musicians, rehearsal and collaboration.
- Treat the hero as the product thesis and keep each page focused on one primary job.
- Use deliberate typography, spacing, palette and component hierarchy.
- Use motion intentionally for feedback and atmosphere; do not scatter animations everywhere.
- Keep the signature element memorable while surrounding UI remains disciplined.
- Always support responsive mobile layouts, visible keyboard focus and reduced motion.
- Treat empty/error states as useful guidance, not decoration.
- Use plain Persian labels describing the action the user controls.

## Hamnavaz direction
- RTL Persian-first UI.
- Premium dark navy/black base.
- Gold as the brand accent.
- Purple neon is the signature interactive glow for online musicians and instruments.
- Neon effects should remain readable and purposeful rather than turning the product into a game UI.

## Process
Brainstorm → compact design plan → critique against Hamnavaz brief → build → visual/browser verification → critique again.
