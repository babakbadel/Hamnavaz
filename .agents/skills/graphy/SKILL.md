# Graphy Skill

Use Graphy as a dependency and impact-analysis layer.

For meaningful changes:
1. Identify changed nodes: pages, components, APIs, services, models, data and infrastructure.
2. Identify inbound/outbound dependencies.
3. Identify critical nodes, bottlenecks and isolated nodes.
4. Estimate change propagation and regression risk.
5. Record important graph findings in the project log.

Do not create decorative graphs when a dependency/impact analysis is sufficient.
